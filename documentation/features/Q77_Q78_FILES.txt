## Quick Start

### 1. Database Migration
npx prisma migrate deploy

### 2. Environment Variables
Copy to .env:
  ERROR_RATE_CRITICAL=1.0
  LATENCY_P95_CRITICAL=3000
  MEMORY_CRITICAL=85
  ROLLBACK_ALERT_EMAILS=oncall@manawa.com
  SLACK_ROLLBACK_WEBHOOK=https://hooks.slack.com/services/...
  SENTRY_DSN=https://key@sentry.io/project

### 3. Start Monitoring
./scripts/rollback-trigger.sh --daemon &

### 4. Start Backup Verification
./scripts/backup-integrity-test.sh --once
# Or add to cron: 0 * * * * cd /opt/manawa/backend && ./scripts/backup-integrity-test.sh --once

### 5. Test Endpoints
curl http://localhost:4000/api/v1/admin/config/versions -H "Authorization: Bearer $JWT"
