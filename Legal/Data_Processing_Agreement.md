# 📋 DATA PROCESSING AGREEMENT — MANAWA

**Effective Date:** 2026-11-14  
**Last Updated:** 2026-11-14

---

## 1. PURPOSE

This agreement establishes the terms under which MANAWA (Data Controller) engages third-party service providers (Data Processors) to process personal data on its behalf, in compliance with GDPR Article 28.

---

## 2. DATA PROCESSOR OBLIGATIONS

Each processor agrees to:

✅ **Process data only on documented instructions**
- Only process data as directed by MANAWA
- No independent use of personal data
- Comply with GDPR and local laws

✅ **Maintain confidentiality**
- Employees must sign confidentiality agreements
- No unauthorized access to data
- Data deleted after contract termination

✅ **Implement security measures**
- Encryption in transit and at rest
- Access controls and authentication
- Regular security audits
- Incident response procedures

✅ **Audit and compliance**
- Annual security audit
- Provide audit reports to MANAWA
- Allow MANAWA to verify compliance
- Notify MANAWA of legal requests

✅ **Sub-processor management**
- Notify MANAWA of any sub-processors
- Require sub-processors to sign DPA
- MANAWA can object to new sub-processors

---

## 3. MANAWA'S OBLIGATIONS

MANAWA agrees to:

✅ **Provide clear instructions**
- Define what data can be processed
- Specify processing purposes
- Outline data retention periods
- Describe security requirements

✅ **Monitor compliance**
- Regular compliance audits
- Request proof of security measures
- Verify data protection practices
- Review incident reports

---

## 4. DATA SUBJECT RIGHTS

Processors must support MANAWA in enabling:

✅ **Right to access**
- Provide data in machine-readable format
- Respond within 30 days

✅ **Right to erasure**
- Delete data upon request
- Confirm deletion in writing

✅ **Right to rectification**
- Allow users to correct data
- Update records promptly

✅ **Right to data portability**
- Export data in structured format
- Support data transfers

---

## 5. DATA BREACH NOTIFICATION

If a breach occurs, processor must:

1. **Notify MANAWA within 24 hours**
   - Details of breach
   - Data affected
   - Likely consequences
   - Measures taken

2. **Assist with notifications**
   - Help notify affected users
   - Notify authorities if required
   - Provide evidence for investigation

3. **Prevent recurrence**
   - Root cause analysis
   - Corrective actions
   - Audit verification

---

## 6. DATA DELETION & RETURN

Upon termination:

✅ **Delete personal data**
- Remove all copies of user data
- Confirm deletion in writing
- Retain only if legally required

✅ **Audit trail**
- Maintain records of deletion
- Provide deletion certificates
- Archive for 7 years

---

## 7. TERM & TERMINATION

- Agreement effective upon signature
- Renews annually unless terminated
- Either party may terminate with 30 days notice
- Data handling terms survive termination

---

## 8. INTERNATIONAL TRANSFERS

For data transfers outside EU:

✅ **Standard Contractual Clauses (SCCs)**
- Required for non-EU processors
- Transfers must comply with GDPR Chapter 5

✅ **Adequacy Decisions**
- EU adequately protects data
- Processors must maintain equivalence
