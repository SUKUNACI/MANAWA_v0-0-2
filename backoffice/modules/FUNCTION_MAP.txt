helpers-data.js (277 lines) - API/CSRF/Formatting
================================================================================

1. apiCall(endpoint, options = {})
   Standardized fetch wrapper with:
   - CSRF token injection
   - Timeout handling (30s default)
   - Retry logic for 5xx errors
   - Multiple response format support
   
   Parameters:
   - endpoint: string (e.g., '/api/users')
   - options: { method, body, headers, timeout, retries }
   
2. getCsrfToken()
   Extracts CSRF token from:
   1. Meta tag (meta[name="csrf-token"])
   2. Cookie (XSRF-TOKEN)
   3. Hidden input (input[name="_csrf"])
   
3. verifyCsrfToken()
   Checks if CSRF token exists and is non-empty
   
4. formatDate(date, format = 'short')
   Formats date using Intl.toLocaleDateString
   Formats: 'short', 'long', 'full', 'time', 'datetime'
   
5. formatRelativeTime(date)
   Formats date relative to now
   Examples: "5 seconds ago", "2 hours ago", "3 days ago"
   
6. formatCurrency(amount, currency = 'USD', decimals = 2)
   Formats number as currency using Intl.NumberFormat
   Examples: "$1,234.56", "€2 345,67"
   
7. formatNumber(num, decimals = 1)
   Formats large numbers with K/M/B suffix
   Examples: "1.5K", "3.2M", "1.8B"

helpers.js (269 lines) - Barrel Coordinator + DRY Utilities
================================================================================

1. loadModuleTable(config, page = 1)
   Generic paginated table loader (ELIMINATES 20+ REPETITIONS)
   
   Config:
   - endpoint: API URL (supports {page} and {limit} placeholders)
   - selector: { tbody, empty, pagination } - DOM IDs
   - columns: Array of column configs
   - onRowClick: Optional row click handler
   - searchInput: Optional search input ID
   - filters: Optional additional filters
   - limit: Optional page limit (default 50)
   
   Returns: { items, total, page, pages }
   
   Usage:
   ```javascript
   export async function loadUsers(page = 1) {
     return loadModuleTable({
       endpoint: '/api/users?page={page}&limit={limit}',
       selector: { tbody: 'users-tbody', pagination: 'pag' },
       columns: [{ key: 'name', label: 'Name' }],
       searchInput: 'search'
     }, page);
   }
   ```
   
2. debounceModuleTableSearch(config, debounceKey, delay = 300)
   Debounce wrapper for module table search
   
   Usage:
   ```html
   <input oninput="debounceModuleTableSearch(config, 'users', 300)" />
   ```
