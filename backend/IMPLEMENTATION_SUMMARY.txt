================================================================================
NEW API ENDPOINTS
================================================================================

POST /api/auth/login (ENHANCED)
  Returns: 200 OK, 401 Unauthorized, 429 Too Many Requests
  Headers: X-Attempts-Remaining, Retry-After

POST /api/auth/unlock (NEW - ADMIN ONLY)
  Auth: Bearer token (ADMIN role required)
  Body: { email, reason? }
  Response: { ok, message, email }

GET /api/auth/login-history (NEW - AUTHENTICATED)
  Auth: Bearer token
  Returns: Array of login attempts
  Query: ?limit=20 (max 100)

GET /api/admin/user/:id/security (NEW - ADMIN ONLY)
  Auth: Bearer token (ADMIN role required)
  Returns: User info + security status + recent attempts

================================================================================
BEHAVIOR
================================================================================

SUCCESSFUL LOGIN:
  - Check lockout status
  - Verify credentials
  - Clear failed attempts
  - Log success
  - Return tokens (200 OK)

FAILED PASSWORD (Attempts 1-4):
  - Increment counter in Redis
  - Log failure to database
  - Return 401 Unauthorized
  - Set X-Attempts-Remaining header

FAILED PASSWORD (Attempt 5):
  - Increment to 5
  - Lock account in Redis
  - Log failure
  - Return 401 Unauthorized

LOCKOUT TRIGGERED (Attempt 6+):
  - Return 429 Too Many Requests immediately
  - Set Retry-After header with remaining seconds
  - Return error code: ACCOUNT_LOCKED

AUTOMATIC UNLOCK:
  - After 15 minutes, Redis key expires
  - User can login again automatically

ADMIN UNLOCK:
  - Clears lockout and failed attempts
  - User can login immediately
  - Action logged to adminLog

================================================================================
SECURITY FEATURES
================================================================================

* Email Normalization
  - Prevents bypass with different casing

* Distributed System Support
  - Redis enables tracking across servers

* Fallback Support
  - In-memory cache if Redis unavailable

* Audit Trail
  - Every attempt logged to database
  - Records: user, email, status, IP, user agent, metadata

* Timing Attack Prevention
  - Consistent error messages

* Rate Limiting
  - Global IP limit: 10 req/15 min per IP
  - Per-account limit: 5 failed/15 min

* Admin Unlock
  - Requires ADMIN role
  - Logged to adminLog

* User Transparency
  - Users can view their login history
  - See IP addresses and timestamps
