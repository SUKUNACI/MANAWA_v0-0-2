Key Features:
  ✅ 5s timeout for all third-party APIs
  ✅ 30s Express middleware timeout for /payments and /subscriptions
  ✅ Error differentiation: timeout ≠ rate-limit ≠ auth-invalid ≠ server-error
  ✅ Clear client messages (never generic "Internal Error")
  ✅ Fallback strategies: SMS↔Email, GeniusPay clear message
  ✅ Sentry integration for monitoring
  ✅ Separate logging for timeout errors (TIMEOUT_ERR code)

Error Classification (5 types):
  1. Timeout (504) - "Délai d'attente dépassé"
  2. Rate-Limit (429) - "Trop de requêtes"
  3. Auth Invalid (503) - "Configuration invalide"
  4. Server Error (503) - "Erreur serveur"
  5. Network Error (503) - "Impossible de contacter"

Fallback Strategies:
  - Twilio SMS fails → Email OTP fallback
  - Mailjet email fails → SMS notification fallback
  - GeniusPay payment fails → Clear "Paiement échoué" message
