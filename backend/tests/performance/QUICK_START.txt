✅ SUCCESS CRITERIA:

  Baseline (100 VUs):
  ✓ p95 response time <500ms
  ✓ Error rate <1%
  ✓ Throughput >1000 req/sec

  Peak (1000 VUs):
  ✓ p95 response time <1s
  ✓ Error rate <1.5%
  ✓ Graceful degradation

  Stress (5000 VUs):
  ✓ Clear breaking point
  ✓ Error rate <10%
  ✓ Full recovery after load

================================================================================

🛠️ TROUBLESHOOTING:

  Problem: "K6 command not found"
  → Install: brew install k6 (macOS) or apt-get install k6 (Linux)

  Problem: "Backend not responding"
  → Start backend: cd .. && npm start

  Problem: "Permission denied on run-tests.sh"
  → Fix: chmod +x run-tests.sh

  Problem: "High error rate in tests"
  → Check: tail -f ../logs/error.log
