OVERVIEW
================================================================================

The General Data Protection Regulation (GDPR) protects personal data of EU 
residents. This checklist ensures MANAWA meets all requirements.

================================================================================
REQUIREMENTS CHECKLIST
================================================================================

1. LAWFUL BASIS FOR PROCESSING
   ✅ User data collected with explicit consent
   ✅ Consent form clearly displayed before signup
   ✅ Separate checkbox for marketing communications
   ✅ Easy opt-out mechanism

2. DATA SUBJECT RIGHTS
   ✅ Right to access: Users can download their data (JSON export)
   ✅ Right to erasure: "Delete my account" button removes all data
   ✅ Right to rectification: Users can edit their profile
   ✅ Right to data portability: Export data in machine-readable format
   ✅ Right to restrict processing: Opt-out of analytics/tracking

3. PRIVACY POLICY
   ✅ Written in clear, plain language
   ✅ Explains what data is collected
   ✅ Explains why data is collected
   ✅ Explains how data is stored
   ✅ Explains data retention periods
   ✅ Explains who has access to data
   ✅ Lists all third-party processors
   ✅ Contact info for Data Protection Officer

4. DATA PROTECTION BY DEFAULT
   ✅ Encryption in transit (HTTPS/TLS)
   ✅ Encryption at rest (database encryption)
   ✅ Secure password hashing (bcrypt)
   ✅ Access controls (role-based)
   ✅ Audit logging enabled
   ✅ Regular backups

5. THIRD-PARTY AGREEMENTS (DPA)
   ✅ GeniusPay — Data Processing Agreement signed
   ✅ Firebase — DPA in place
   ✅ Mailjet — DPA in place
   ✅ Twilio — DPA in place
   ✅ Cloudinary — DPA in place
   ✅ All DPAs include subprocessor clauses

6. DATA SUBJECT REQUESTS
   ✅ Process for handling access requests (< 30 days)
   ✅ Process for handling deletion requests (< 30 days)
   ✅ Process for handling portability requests (< 30 days)
   ✅ Documentation of all requests and responses

7. DATA BREACH NOTIFICATION
   ✅ Incident response plan documented
   ✅ Can notify authorities within 72 hours
   ✅ Can notify affected users within 72 hours
   ✅ Breach logging enabled (audit trail)

8. CONSENT MANAGEMENT
   ✅ Consent records stored (timestamp + version)
   ✅ Users can withdraw consent anytime
   ✅ Withdrawal processed within 30 days
   ✅ No service suspension for withdrawal

9. CHILDREN'S DATA (< 16 years)
   ✅ Users must be 18+ (Terms of Service)
   ✅ No collection of children's data
   ✅ Parental consent not required (no child users)

10. TRANSFERS OUTSIDE EU
    ✅ Firebase: Standard Contractual Clauses (SCCs) in place
    ✅ GeniusPay: Operates within EU
    ✅ No transfers to countries without adequacy decision
